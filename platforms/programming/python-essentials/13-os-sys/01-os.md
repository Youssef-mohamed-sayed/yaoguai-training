## Introduction

`os` provides operating-system functions. Use `os.getcwd()`, `os.listdir()`, `os.path.exists()`, `os.environ.get()`, and `os.makedirs(..., exist_ok=True)`. Prefer `pathlib` for many path operations. Treat paths and environment variables as potentially missing or untrusted.

## Core Concepts

Work through the explanation before running the example. Identify the input, the operation performed, and the output or side effect. Python is case-sensitive; indentation defines blocks; values have types; and errors should be handled at the point where the program can respond meaningfully.

## Syntax and Example

```python
import os
print(os.getcwd())
print(os.listdir("."))
home = os.environ.get("HOME") or os.environ.get("USERPROFILE")
print(home)
os.makedirs("reports/daily", exist_ok=True)
```
