# Package Management

## Module description
This module develops practical skills in **package management**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Manage packages using the correct distribution tools.
- Complete the exercises and explain why each command works.

## Lessons
- [Apt And Dpkg](01-apt-and-dpkg.md)
- [Dnf Rpm And Pacman](02-dnf-rpm-and-pacman.md)

## Practical exercises
- Complete the hands-on practice in [Debian and Ubuntu: apt and dpkg](01-apt-and-dpkg.md).
- Complete the hands-on practice in [Fedora/RHEL: dnf and rpm; Arch: pacman](02-dnf-rpm-and-pacman.md).

## Prerequisites
- A Linux system; use only the package manager for its distribution.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
