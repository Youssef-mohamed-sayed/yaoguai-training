# Processes and Services

## Module description
This module develops practical skills in **processes and services**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Inspect processes, signals, services, and logs.
- Complete the exercises and explain why each command works.

## Lessons
- [Processes Signals And Monitoring](01-processes-signals-and-monitoring.md)
- [Services Systemd And Logs](02-services-systemd-and-logs.md)

## Practical exercises
- Complete the hands-on practice in [Processes, Signals, and Monitoring](01-processes-signals-and-monitoring.md).
- Complete the hands-on practice in [Services, systemd, and Logs](02-services-systemd-and-logs.md).

## Prerequisites
- Modules 01–05; systemd commands require a system using systemd.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
