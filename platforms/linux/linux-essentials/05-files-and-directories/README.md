# Files and Directories

## Module description
This module develops practical skills in **files and directories**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Create, inspect, copy, move, and safely remove files.
- Complete the exercises and explain why each command works.

## Lessons
- [Create Copy Move And Remove](01-create-copy-move-and-remove.md)
- [Reading And Inspecting Files](02-reading-and-inspecting-files.md)

## Practical exercises
- Complete the practice exercises and self-checks in [Create, Copy, Move, and Remove Files](01-create-copy-move-and-remove.md).
- Complete the practice exercises and self-checks in [Reading and Inspecting Files](02-reading-and-inspecting-files.md).

## Prerequisites
- Modules 01–04.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
