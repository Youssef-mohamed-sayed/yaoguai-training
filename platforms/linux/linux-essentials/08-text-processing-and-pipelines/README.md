# Text Processing and Pipelines

## Module description
This module develops practical skills in **text processing and pipelines**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Analyze text and logs using streams and command pipelines.
- Complete the exercises and explain why each command works.

## Lessons
- [Streams Redirection And Pipes](01-streams-redirection-and-pipes.md)
- [Grep Sed Awk And Log Analysis](02-grep-sed-awk-and-log-analysis.md)

## Practical exercises
- Complete the practice exercises and self-checks in [Standard Streams, Redirection, and Pipes](01-streams-redirection-and-pipes.md).
- Complete the practice exercises and self-checks in [grep, sed, awk, and Practical Log Analysis](02-grep-sed-awk-and-log-analysis.md).

## Prerequisites
- Modules 01–05.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
