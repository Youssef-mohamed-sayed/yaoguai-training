# Introduction to Linux

## Module description
This module develops practical skills in **introduction to linux**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Explain Linux, GNU/Linux, kernel architecture, and open-source foundations.
- Complete the exercises and explain why each command works.

## Lessons
- [What Is Linux](01-what-is-linux.md)
- [Linux Architecture And Open Source](02-linux-architecture-and-open-source.md)

## Practical exercises
- Complete the practice exercises and self-checks in [What Is Linux?](01-what-is-linux.md).
- Complete the practice exercises and self-checks in [Linux Architecture and Open Source](02-linux-architecture-and-open-source.md).

## Prerequisites
- Basic computer literacy.
