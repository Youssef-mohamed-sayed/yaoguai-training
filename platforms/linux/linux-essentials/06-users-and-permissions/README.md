# Users and Permissions

## Module description
This module develops practical skills in **users and permissions**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Manage identities, ownership, access modes, and special permissions.
- Complete the exercises and explain why each command works.

## Lessons
- [Users Groups And Account Files](01-users-groups-and-account-files.md)
- [Permissions Chmod Chown And Sudo](02-permissions-chmod-chown-and-sudo.md)
- [Special Permissions And Least Privilege](03-special-permissions-and-least-privilege.md)

## Practical exercises
- Complete the practice exercises and self-checks in [Users, Groups, and Account Databases](01-users-groups-and-account-files.md).
- Complete the practice exercises and self-checks in [Permissions, chmod, chown, and sudo](02-permissions-chmod-chown-and-sudo.md).
- Complete the practice exercises and self-checks in [SUID, SGID, Sticky Bit, and Least Privilege](03-special-permissions-and-least-privilege.md).

## Prerequisites
- Modules 01–05; administrator access in a disposable VM for account-management tasks.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
