# Bash Scripting

## Module description
This module develops practical skills in **bash scripting**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Write maintainable Bash scripts with safe input handling.
- Complete the exercises and explain why each command works.

## Lessons
- [Script Structure Variables And Input](01-script-structure-variables-and-input.md)
- [Conditionals Loops Functions And Arrays](02-conditionals-loops-functions-and-arrays.md)
- [Safe Scripting Debugging And Error Handling](03-safe-scripting-debugging-and-error-handling.md)

## Practical exercises
- Complete the hands-on practice in [Scripts, Variables, Arguments, and Input](01-script-structure-variables-and-input.md).
- Complete the hands-on practice in [Conditionals, Loops, Functions, and Arrays](02-conditionals-loops-functions-and-arrays.md).
- Complete the hands-on practice in [Safe Scripting, Debugging, and Error Handling](03-safe-scripting-debugging-and-error-handling.md).

## Prerequisites
- Modules 04–08 and Bash.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
