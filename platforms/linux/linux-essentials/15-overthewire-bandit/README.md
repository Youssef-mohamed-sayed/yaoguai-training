# OverTheWire: Bandit

## Module description
This module develops practical skills in **overthewire: bandit**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Apply Linux command-line skills in the Bandit wargame.
- Complete the exercises and explain why each command works.
