# Searching and Security Inspection

## Module description
This module develops practical skills in **searching and security inspection**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Find files and perform safe defensive permission reviews.
- Complete the exercises and explain why each command works.

## Lessons
- [Find Locate And Whereis](01-find-locate-and-whereis.md)
- [Defensive Filesystem Audit](02-defensive-filesystem-audit.md)

## Practical exercises
- Complete the hands-on practice in [Find, locate, whereis, and which](01-find-locate-and-whereis.md).
- Complete the hands-on practice in [Defensive Filesystem and Permission Auditing](02-defensive-filesystem-audit.md).

## Prerequisites
- Modules 03–08.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
