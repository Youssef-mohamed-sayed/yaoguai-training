# Practical Labs

## Module description
This module develops practical skills in **practical labs**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Combine Linux skills in realistic administration and security labs.
- Complete the exercises and explain why each command works.

## Lessons
- [Lab Filesystem And Permissions](01-lab-filesystem-and-permissions.md)
- [Lab Authentication Log Analysis](02-lab-authentication-log-analysis.md)
- [Lab Processes Services And Ssh](03-lab-processes-services-and-ssh.md)
- [Lab Build A Log Analyzer](04-lab-build-a-log-analyzer.md)

## Practical exercises
- Complete the hands-on practice in [Lab: Filesystem, Users, and Permissions](01-lab-filesystem-and-permissions.md).
- Complete the hands-on practice in [Lab: Authentication Log Analysis](02-lab-authentication-log-analysis.md).
- Complete the hands-on practice in [Lab: Processes, Services, and Secure Remote Access](03-lab-processes-services-and-ssh.md).
- Complete the hands-on practice in [Lab: Build a Bash Log Analyzer](04-lab-build-a-log-analyzer.md).

## Prerequisites
- Modules 01–13 and a disposable Linux VM.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
