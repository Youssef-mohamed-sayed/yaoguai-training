# SSH and Remote Access

## Module description
This module develops practical skills in **ssh and remote access**. Work through the lessons in order and execute examples in a safe lab.

## Learning objectives
- Connect and transfer files securely with OpenSSH.
- Complete the exercises and explain why each command works.

## Lessons
- [Ssh Client And Host Verification](01-ssh-client-and-host-verification.md)
- [Ssh Keys Agent And File Transfer](02-ssh-keys-agent-and-file-transfer.md)

## Practical exercises
- Complete the hands-on practice in [SSH Connections and Host-Key Verification](01-ssh-client-and-host-verification.md).
- Complete the hands-on practice in [SSH Keys, ssh-agent, SCP, and SFTP](02-ssh-keys-agent-and-file-transfer.md).

## Prerequisites
- Modules 04–06 and network connectivity.

## Completion checklist
- [ ] Read every lesson in order.
- [ ] Run the commands in a safe environment.
- [ ] Complete each practical exercise.
- [ ] Explain the key takeaways without copying the lesson.
