# Module 2 — Addressing

> Difficulty: Beginner → Intermediate

Devices need addresses to find each other. This module covers the two address types and how they relate.

1. [IPv4 Addressing](ipv4.md)
2. [MAC Addresses](mac-addresses.md)
3. [Subnetting](subnetting.md) — take your time here
4. [ARP](arp.md)

| Term | Layer | Looks like | Scope |
|------|-------|-----------|-------|
| MAC address | 2 | `aa:bb:cc:dd:ee:ff` | Local network segment |
| IP address | 3 | `192.168.1.10` | Routable across networks |
| Port | 4 | `443` | A service on a host |
