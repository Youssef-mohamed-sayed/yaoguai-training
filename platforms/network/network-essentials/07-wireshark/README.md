# Module 7 — Wireshark

> Difficulty: Beginner → Intermediate

Wireshark shows the packets actually crossing a network interface. If Nmap is a flashlight you shine at a target, Wireshark is a microscope on the traffic.

## ⚠️ Authorization

Capture only on **your own machine/lab network**, CTF environments, or networks where you have **explicit permission**. Capturing other people's traffic without authorisation can be illegal and violates privacy.
